# CLI-Анализатор журналов событий

**Студент:** Белименко А. Д.
**Язык:** C# (.NET 8.0)
**ОС:** Ubuntu 26.04 (WSL)

## Бизнес-требования
Приложение предназначено для быстрого поиска частых ошибок и их источников в журналах. 
Поддерживает фильтрацию по времени, уровню и источнику, а также подсчет статистики.

## Реализованный функционал
* Построчное чтение файла (без загрузки всего файла в память).
* Фильтрация по `from`, `to`, `level`, `source`.
* Подсчет корректных и ошибочных строк.
* Вывод сводки в терминал.
* Обработка ошибок с указанием номера строки.

## Развертывание
1. Установите .NET 8.0 SDK.
2. Склонируйте репозиторий.
3. Перейдите в папку проекта: `cd LogAnalyzer`.
4. Соберите проект: `dotnet build`.
